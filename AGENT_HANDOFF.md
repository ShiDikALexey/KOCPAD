## 1. Что это за проект

**KOCPAD** — блокнот для markdown-заметок на Windows: «как Блокнот, но ничего не
теряет». Идея: обычные `.md` файлы в папке пользователя, мгновенный запуск,
автосохранение, живой предпросмотр, теги и связи, никаких аккаунтов и облака.

- Репозиторий: <https://github.com/ShiDikALexey/KOCPAD>
- Лицензия: MIT
- Стек: TypeScript + Vite 8 + CodeMirror 6 (ядро) и Tauri 2 + Rust (оболочка).
- Интерфейс и документация — на русском; код, комментарии и коммиты — на английском.

## 3. Ключевые решения и почему

1. **Tauri 2, а не Electron.** Установщик ~1.5–2 МБ вместо ~100 МБ, системный
   WebView2, нативный Rust для файлов, хоткея и перехвата закрытия.
2. **Файлы `.md`, а не база.** Нет миграций формата, папку можно синхронизировать
   чем угодно и открыть в Obsidian/VS Code. «Удалил приложение — заметки остались».
3. **Три реализации хранилища** (`src/storage/`): Tauri (нативные команды),
   браузер (File System Access API + IndexedDB), демо (в памяти, `?demo=1`).
   Логика не знает, где лежат файлы — это позволяет тестировать в браузере.
4. **Атомарная запись** в Rust: `.kocpad-tmp` + rename, чтобы не оставить
   половинчатый файл.
5. **Черновики = документ без файла** (`draft:<id>`). С 1.4.1 они хранятся
   отдельным списком и не удаляются при закрытии вкладки.
6. **События стора разделены по стоимости**: `docs` (структурные изменения),
   `dirty` (правки текста), `tree`, `root`, `settings`, `drafts`, `status`.
   Дерево и вкладки не перерисовываются на каждый символ — это закреплено тестом.
7. **Рендер markdown** — marked + DOMPurify + highlight.js, без плагинов и CSP-дыр.
   Ссылки `[[…]]` и теги `#…` разбираются отдельными модулями и игнорируют блоки кода.
8. **Перехват закрытия окна**: Rust `FRONTEND_READY` + `window.__kocpadRequestClose`,
   потому что вебвью не может сам заблокировать закрытие ОС.
9. **Автообновления** используют собственный minisign-ключ (не сертификат Windows):
   публичный — в `tauri.conf.json`, приватный — в GitHub Secrets, `latest.json`
   генерируется релизным джобом.
10. **CI без сюрпризов**: BOM-guard для конфигов, e2e на Linux, сборка на Windows,
    `SHA256SUMS.txt` в каждом релизе.

## 6. Найденные и исправленные проблемы (чтобы не наступить снова)

| Проблема | Причина | Решение |
|---|---|---|
| Дерево/вкладки перерисовывались на каждый символ | `updateContent` эмитил `docs` | тема `dirty` + debounce в подписчиках; регресс-тест |
| `Ctrl+W` на черновике удалял его | `closeTabNow` вызывал `deleteDraftDoc` | закрытие вкладки больше не удаляет черновик |
| Закрытие окна спрашивало про черновики | диалог в `handleCloseRequest` | убран; автосохранение + восстановление вкладок |
| `latest.json` не появлялся в релизе | не был написан генератор | `scripts/make-latest-json.cjs` + шаг в release |
| Сборка падала бы без ключа | `createUpdaterArtifacts: true` требует ключ | `scripts/enable-updater.cjs` включает флаг только при секрете |
| Панель форматирования «съедала» клики | `.main` был grid на 3 строки | переведён на flex-колонку |
| Неактивное выделение становилось сиреневым | CM не рисует выделение без фокуса, срабатывал системный `::selection` | глобальный `::selection` + `--selection` темы |
| BOM в `tauri.conf.json` ломал сборку | PowerShell `Set-Content` добавляет BOM | bump-скрипт пишет UTF-8 без BOM; в CI BOM-guard |
| Кириллица в `main.ts` превратилась в кракозябры | правка файла через PowerShell с `Get-Content`/`Set-Content` в 5.1 | правки — только инструментами с UTF-8 (или Node-скриптами); проверка на mojibake |
| Тест «двойной клик по меню» падал | обработчик закрытия в capture-фазе опережал кнопку | внешние клики закрывают меню, но клик по кнопке-якорю исключён |
| **Картинки не показывались в собранном приложении** | в production-CSP не было `blob:`, dev/e2e этого не видели | `img-src` c `blob:` и `https:` |
| **Сбой записи черновика считался успехом** | `savedContent` выставлялся до проверки `persistDrafts()` | документ остаётся dirty, ошибка показывается, закрытие не молчит |
| **Смена папки могла выбросить несохранённые файлы** | `saveAll()` возвращал `void`, ошибки терялись | `saveAll()` возвращает число неудач, переключение отменяется |
| **Открытая заново заметка показывала старый текст** | кэш `EditorState` не сверялся с содержимым | кэш учитывает текст; `forget()` при закрытии/переименовании/удалении |
| **Заметка, начинающаяся с `---`, теряла тело** | любой блок между `---` считался front matter | front matter только если каждая строка — `key: value` |
| **Удаление пачки закрывало вкладки и неудалённых файлов** | закрывались все совпавшие пути | закрываются только реально удалённые |
| **Инъекция через внешнюю ссылку** | `cmd /C start "" <url>` с непроверенными кавычками | крейт `open` (`ShellExecuteW`), только http/https/mailto |
| **Конфликт глобального хоткея валил запуск** | `with_shortcut(...).expect(...)` | регистрация в `setup()` с предупреждением вместо паники |
| **Коллизия temp-файлов атомарной записи** | `with_extension("kocpad-tmp")` у `a.md` и `a.txt` | уникальное имя + `sync_all()` |
| **Статистика пересчитывалась на каждое нажатие** | `setCursor` вызывал полный `renderStats()` | debounce, как у остальных обновлений |
| **Дублировались тосты об ошибке** | `report()` шёл и в `status`, и в `onError` | один канал ошибок |
| **Подпись Authenticode ломала бы автообновления** | `.sig` считался до `signtool` | после подписи инсталлятор пере-подписывается ключом апдейтера |

## 7. Состояние подписи установщика (важно)

С июня 2023 приватные ключи подписи кода обязаны храниться на FIPS-140-2
железе (токен или облачный HSM) — скачиваемый `.pfx` больше не выдают.

| Вариант | Доступность | SmartScreen |
|---|---|---|
| Azure Artifact Signing (~$10/мес) | юрлица США/Канада/ЕС/UK (3 года налоговой истории), физлица — только США/Канада | репутация накапливается |
| Зарубежные OV/EV (Sectigo, DigiCert, GlobalSign) | с 2022 не работают с РФ, в 2026 отзывают | недоступно |
| Российский ОТУЦ | доступен | корень не в Microsoft Trusted Root → предупреждение, вероятно, останется |
| Самоподписанный | всегда | не помогает без раскатки корня |
| Microsoft Store (MSIX) | нужен аккаунт разработчика | Microsoft переподписывает, предупреждений нет |

Вывод: пока выпускаем **неподписанные установщики + `SHA256SUMS.txt`**, а
обновления защищены minisign-ключом апдейтера. Шаг `signtool` в CI готов и
включится при появлении совместимого сертификата (секреты
`WINDOWS_CERTIFICATE` / `WINDOWS_CERTIFICATE_PASSWORD`).

## 8. Что осталось / известные ограничения

Аудит 2026-11-21 (четыре независимых проверки: документация, фронтенд, Rust/CI,
продукт) подтвердил, что это **бета, а не стабильный 1.x**. Честный список
незакрытого:

**Данные и надёжность**
- ✅ **Внешние правки отслеживаются** (волна 1, шаг 1): `Storage.stat()`, сверка
  mtime/size перед записью, диалог «перечитать / оставить моё / сохранить копию»,
  проверка по фокусу окна, F5 перечитывает активную заметку.
- ✅ **Журнал восстановления** (волна 1, шаг 2): снапшот грязного файла раз в ~0.5 с
  в профиль (Rust `recovery_*` / localStorage в браузере), при старте диалог
  «Восстановить / Открыть файл / Удалить», после сохранения журнал чистится.
- **Удаление необратимо** — нет корзины/истории версий; по решению владельца
  будет внутренняя корзина KOCPAD с авт удалением через 30 дней (шаг 4 волны 1).
- **Кодировки:** только UTF-8; cp1251/UTF-16 `.txt` не откроются, CRLF после
  правки сохраняется как LF, BOM не снимается (шаг 3 волны 1).
- **`Cargo.lock` не закоммичен** (нет локального Rust для генерации) — сборки
  менее воспроизводимы; `tauri = "2"` не запинен.

**Безопасность/архитектура**
- Кастомные fs-команды не ограничены рабочей папкой (нет `canonicalize` +
  `starts_with(root)`); картинка с `../../` может прочитать произвольный файл.
- Нет single-instance guard: второй запуск не координируется, оба пишут файлы.
- Тяжёлые fs-команды синхронные → выполняются на UI-потоке (большая папка
  подвешивает окно).
- CSP можно ужесточить (`default-src 'none'`, `script-src 'self'`), сейчас
  `default-src` разрешает blob/data для скриптов.

**Продукт**
- Экспорт/печать: картинки не встраиваются, `[[ссылки]]` остаются текстом, в PDF
  печатается абсолютный путь файла.
- Поиск: нет regex/замены по папке, гонка результатов без requestId.
- Клавиатура: `Del` в дереве не работает (хотя подсказка есть), меню и модалки
  без focus-trap/стрелок.
- Wiki links: переименование не обновляет ссылки, нет «создать заметку» по клику.
- Форматирование продублировано в 4 местах (хоткеи, панель, ПКМ, палитра).
- Нет file associations / tray / jump list; формат MSI-обновления не проверен.

**Процесс**
- Нет нативного e2e на Windows против собранного `.exe` (все 36 тестов — Chromium
  на Vite), чистая машина не проверялась.
- Нет ревью второй парой глаз: коммиты идут прямо в `main`/`beta`.

**Организационное**
- **Переименование** — ждёт имя от пользователя (см. вопрос в разделе 11).
- **Ключ подписи обновлений** хранится только на старом ПК; при переносе его нужно
  скопировать руками (без него новые релизы не установятся поверх старых).
- **Git identity** в истории коммитов настроена локально (GitHub noreply) — на
  новом ПК при желании задать свою.

## 9. Конвенции проекта

- Коммиты: английский, повелительное наклонение, тело объясняет «зачем».
  Пример: `fix: stop rebuilding the sidebar on every keystroke`.
- Код и комментарии — английский; UI-строки, README и docs — русский.
- Перед пушем: `npm run typecheck`, `npm run build`, `npm run test:e2e`.
- Версия: `node scripts/bump-version.cjs x.y.z` (три файла, UTF-8 без BOM).
- Релиз: bump → commit → `git tag -a vX.Y.Z -m "..."` → push main + tag → CI.
- Скриншоты для README снимаются Playwright-скриптом на 1440×900 в светлой теме
  (пример — в истории коммитов); после снятия — проверить ссылки в README.
- Не коммитить: `node_modules/`, `dist/`, `src-tauri/target/`, `test-results/`,
  `playwright-report/`, `.tmp/`, ключи и сертификаты.

## 10. Как выпустить релиз (пошагово)

```bash
git checkout main
git merge beta                 # или fast-forward, если договорились
node scripts/bump-version.cjs 1.4.1
git commit -am "release: 1.4.1"
git tag -a v1.4.1 -m "KOCPAD 1.4.1"
git push origin main v1.4.1
```

CI соберёт установщики, `.sig` (если секрет ключа на месте) и `latest.json`,
опубликует релиз с `SHA256SUMS.txt`. Установленная копия увидит обновление
в меню «⋯» → «Проверить обновления…».

## 13. Архив

Архив `KOCPAD-transfer-<дата>.zip` лежит рядом с проектом (не в репозитории).
Внутри: полный git-репозиторий со всеми ветками и тегами, этот файл, документация
и скриншоты. Чего внутри **нет** и что нужно взять отдельно:

- приватный ключ подписи обновлений (`~/.tauri/kocpad.key`);
- сертификат Windows, если появится;
- локальные настройки GitHub-секретов.

Распакуйте, проверьте `git status`, `git log --oneline -5`, `npm ci`,
`npm run test:e2e` — и можно продолжать.
